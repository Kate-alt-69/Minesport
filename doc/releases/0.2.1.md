# Minesport 0.2.1 — World Cache & Export Worker

> **Status: in development.** This release note tracks the main user/dev-facing changes planned for 0.2.1.

## Highlights

### World Cache (WC)

- Adds a persistent parsed world cache under:

```text
<user>/.cache/kastrick's_software/minesport/wc/<launcher>/<instance>/<world>/diem/<dimension>/
```

- Minecraft `.mca` data is decoded in the background into fast Minesport `.chunk` files.
- `.chunk` files store world state, not geometry: block states, Y sections, block entities, entities and scheduled ticks.
- WC updates changed chunks automatically when the selected world changes.
- Overworld, Nether and End are supported first; modded/custom dimensions are deferred.
- Minecraft saves remain the source of truth; WC is disposable/rebuildable cache data.

### Faster Litematica exports

- Litematica exports read selected WC chunks instead of repeatedly parsing large `.mca` region files.
- Geometry/model lookup is skipped completely for Litematica.
- Scheduled block and fluid ticks are preserved.
- Final `.litematic` output is staged before publication so an incomplete file is not shown as finished.

### Bridge → Export Worker

- The old **Minesport Bridge** naming is being replaced by **Minesport Export Worker**.
- Intended artifact naming:

```text
minesport-export-worker-<loader>-<minecraft-version>.jar
```

- Static JSON/model/texture assets are resolved directly from Minecraft/mod JARs where possible.
- The Export Worker is only used when Minesport needs Minecraft's real runtime `BakedModel` data or other runtime-only model behavior.
- Once the baked-model snapshot is captured and saved, the disposable Minecraft worker exits immediately; it does not remain alive for the rest of the export.
- Model snapshots are cached and reused until Minecraft/mod/resource-pack inputs change.

### 2D selection + live 3D preview

- 2D becomes the authoritative selection editor.
- 3D selection/picking is being removed.
- 3D becomes a smooth live preview/thumbnail of the current 2D selection.
- Orbit, pan, zoom and fit remain available.
- Preview updates are debounced/latest-wins so rapid selection changes do not continuously rebuild the scene.

### Export progress / loader cleanup

- Real counted progress is used where totals are known; unknown work stays indeterminate.
- Chunk parsing reports the current decode stage instead of appearing frozen on a region filename.
- Backend completion is separated from the short visual completion animation.
- The Minesport loader uses the new spaced-dot rollercoaster/crash animation and only reveals the Creeper face on successful completion.

### Fresh builds

- `--fresh` clears Minesport build outputs and project-local Gradle state.
- Fresh Gradle builds use `clean build --rerun-tasks --no-build-cache`.
- Global dependency/JDK/Cargo caches remain preserved.

## Naming cleanup

- **Bridge** → **Export Worker**
- **runtime registry/cache** → **model cache** where appropriate
- **world cache / WC** → parsed world-state cache only
- **3D selector** → **3D preview**

Internal compatibility identifiers may keep temporary aliases while the rename is migrated safely.
