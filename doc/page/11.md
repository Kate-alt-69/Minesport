# Page 11 — Find the Minesport Panel in Blender

This page exists because instructions like “open the Minesport panel” are useless if you have never used Blender's sidebar before.

## Open the panel

1. Make sure you are looking at Blender's **3D Viewport** — the big area showing the Minecraft world.
2. Move your mouse over that 3D Viewport.
3. Press **N** on the keyboard.
4. A sidebar opens on the **right edge of the 3D Viewport**.
5. Look at the vertical tabs on that sidebar.
6. Click **Minesport**.

That is the **Minesport panel** used throughout these docs.

## If there is no Minesport tab

Check these in order:

1. Minesport's Blender translator/addon is installed.
2. Blender has **Minesport Dynamic Translator** enabled in its Add-ons/Extensions preferences.
3. You imported a Minesport export using the Minesport importer/translation path.
4. Restart Blender once after installing/updating the addon if the old version was already loaded.

Minesport 0.2.0's addon version is **0.2.0**. If Blender still reports a 0.1.x addon, reinstall/repair the translator from Minesport settings and restart Blender.

## Why some Minesport panels only appear after selecting an object

The FLATTER tools are context-sensitive. The `Minesport FLATTER` panel appears when the active object is a Minesport FLATTER object.

If you do not see it:

1. Open the **Outliner** in the upper-right.
2. Select an object named `FLATTER_...` or `FLATTER_SHAPE_...`.
3. Return to **3D Viewport → N → Minesport**.

You should now see the FLATTER controls and the beginner workflow section.

## What should be inside the FLATTER area

For a FLATTER object, Minesport exposes controls for things such as:

- logical block interaction mode;
- logical overlay/green outline;
- materializing selected Minecraft blocks;
- Liquid Merge/selection tools;
- Minecraft light-block placement;
- selection sets and related FLATTER tools.
