# Page 02 — Minesport Main App

This page explains the desktop app itself. If your goal is Blender editing, the Blender-specific guides start at **[Page 10](10.md)**.

## Left-side activities

Minesport uses a small activity rail on the far left.

### World — folder icon

Use this first.

1. Click the **folder icon**.
2. Click **Open Minecraft world…**.
3. Pick the Minecraft save folder.
4. Minesport reads the world metadata and prepares the 2D map.
5. Use the 2D viewport or coordinate controls to choose what area will be exported.

The world is treated as source data. Export work is performed from a temporary copy rather than writing into your save.

### Export — download arrow

Use this after a world is selected.

The normal controls are:

- **Preset** — optional shortcut for a group of export choices.
- **Name** — output filename.
- **Format** — glTF 2.0 or OBJ + MTL.
- **Objects** — how exported geometry is organized after FLATTER/optimization.
- **Optimization** — a compact one-line status plus safe optimization action.
- **Output folder** — where files are written.
- **Export world** — starts the export.

Runtime-model cache preparation is automatic for supported Fabric exports. If the cache is missing or stale, Export prepares it and reports the work in the bottom task notification instead of requiring a separate manual step.

### Blender — camera/video-style icon

Contains Blender integration status and translator controls when Blender export integration is enabled.

### Tasks — history icon

Contains diagnostics/task controls. Long-running operations are also shown in the compact bottom task notification so the world viewport can stay visible.

### Settings — gear icon

Contains geometry optimization, FLATTER cell size, Blender integration, Assets & Resolver configuration, advanced tools, manual runtime-cache controls, and the documentation browser.

## There is no Project system

Minesport 0.2.0 deliberately does not make you save a separate workspace/project just to remember a world selection. The old “PROJECT / Open / Save / Save As” UI was removed.

## Preflight

Manual Preflight is an **advanced diagnostic**, not a required step before Export. It belongs under Advanced settings and writes its useful progress/result information to the task notification and diagnostics log.
