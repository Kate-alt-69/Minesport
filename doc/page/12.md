# Page 12 — FLATTER for Blender Beginners

This is the page to read when Blender shows one giant object named something like `FLATTER_...` or `FLATTER_SHAPE_...` and you expected thousands of individual Minecraft blocks.

## What FLATTER actually is

FLATTER is Minesport's **logical-block virtualization system**.

A normal Minecraft terrain export can contain an absurd number of duplicate cube faces and Blender objects. FLATTER keeps the **Minecraft block grid as data** while compiling many compatible visible surfaces into a much smaller Blender mesh.

Think of it as two layers:

```text
Minecraft logical blocks     <- the truth Minesport preserves
        ↓
FLATTER render mesh          <- optimized Blender geometry generated from them
```

The visible FLATTER mesh is therefore a **render cache**, not the only copy of your blocks.

That is why you should not treat a FLATTER object like an ordinary hand-modeled Blender mesh and start deleting merged faces in Edit Mode.

## Why one FLATTER object can contain many blocks

Minesport divides eligible blocks into spatial FLATTER cells. The cell size is configurable in the Minesport desktop app, for example 8³, 16³, 32³, or 64³.

Inside a cell, compatible faces can be greedily merged. The original block positions, block IDs/states, materials, UV data, and other FLATTER metadata remain embedded so the Blender addon can still address individual logical blocks.

There are also different geometry classes:

- **SOLID** — full solid/cube-like geometry that can safely use aggressive internal-face culling.
- **SHAPE** — repeated non-full axis-aligned geometry, such as compatible path/slab-like shapes, kept separate from SOLID so unlike shapes are not merged together incorrectly.

## Step 1 — Find the Minesport panel

If you have never opened it, stop here and read **[Page 11 — Find the Minesport Panel](11.md)**.

The short version is:

**3D Viewport → press N → Minesport tab**.

Then select a `FLATTER_...` object in the viewport or Outliner.

## Step 2 — Stay in Object Mode

At the top-left of Blender's 3D Viewport, keep the mode on **Object Mode** for normal FLATTER interaction.

Minesport's direct logical-click handler intentionally passes through when Blender is in another mode.

## Step 3 — Click a Minecraft block inside the FLATTER object

With Minesport 0.2.0:

1. Select/look at the FLATTER terrain.
2. **Left-click a visible Minecraft block surface.**
3. Minesport raycasts the FLATTER mesh and maps that hit back to the logical Minecraft voxel underneath it.
4. The active FLATTER object stores that focused block and its Minecraft coordinates.
5. The logical overlay redraws immediately.
6. The focused/selected logical block gets the stronger **green 1×1×1 outline**.

You no longer need to discover and manually start a separate FLATTER Edit Mode just to make normal clicks address blocks.

### Selection modifiers

In the default **Select** interaction:

- **LMB** — select/focus a logical block.
- **Shift + LMB** — add that logical block to the selection.
- **Ctrl + LMB** — remove that logical block from the selection.
- **Alt + LMB** — Minesport intentionally passes the click back to Blender instead of consuming it.

Clicks that do not hit FLATTER geometry also pass through to normal Blender behavior.

## Step 4 — Understand the Interaction dropdown

Inside **N-panel → Minesport → Minesport FLATTER / FLATTER Workflow**, the interaction mode tells Minesport what a logical click should do.

### Select

Use this most of the time. Clicking changes the logical voxel selection without exploding the optimized mesh into thousands of real objects.

### Inspect

Focus/read the Minecraft block without changing the logical selection set.

### Box Select

First click chooses corner A, second click chooses corner B. Minesport selects occupied logical blocks inside that 3D box. Shift adds; Ctrl removes.

### Materialize

Clicking turns that logical Minecraft block into a **real Blender mesh object** and removes that block from the parent FLATTER grid.

Use this only when you need ordinary Blender-object behavior for that specific block — for example moving it, animating it independently, applying physics, or doing mesh operations that FLATTER's logical layer does not represent directly.

## What “Materialize” means

Before:

```text
FLATTER object
└─ logical block at X/Y/Z
```

After materializing that block:

```text
FLATTER object                 real Blender block object
(logical cell removed)   +     (editable/movable/animatable)
```

If the block is still compatible with its original FLATTER cell and you have not left it in an invalid transformed state, Minesport can return it to FLATTER and rebuild the optimized mesh.

## Liquid Merge

Liquid Merge is a FLATTER animation/devirtualization control for selected voxels.

- **ON** — selected voxels stay represented inside the greedy FLATTER render mesh.
- **OFF** — selected voxels become live Blender block geometry while the parent FLATTER mesh is rebuilt without them.

This is useful for animation/physics workflows where blocks need to appear as ordinary objects only during the frames where they actually move.

## Logical overlay modes

The Minesport object properties include a **Logical overlay** setting:

- **Selected only** — recommended everyday mode; only the focused/selected logical block gets the strong outline.
- **Full cell** — diagnostic view showing the complete logical voxel grid. Useful when learning/debugging, but visually busy.
- **Off** — no logical wireframe overlay.

If the whole terrain looks like a giant grid, you probably enabled **Full cell**. Switch back to **Selected only**.

## Why the green outline might not appear

Check these in order:

1. Blender is in **Object Mode**.
2. The addon is Minesport Dynamic Translator **0.2.0 or newer**.
3. The object really has Minesport FLATTER metadata — selecting it should reveal the Minesport FLATTER panel.
4. Logical overlay is not set to **Off**.
5. You clicked actual visible FLATTER geometry, not an unrelated object sitting in front of it.
6. If you imported before updating the addon, restart Blender and re-import/reopen after the addon update.

See **[Page 20 — Troubleshooting](20.md)** if those checks do not solve it.
