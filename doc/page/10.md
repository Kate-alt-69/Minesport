# Page 10 — Blender Beginner Basics

You do **not** need to become a Blender expert before using Minesport. You only need a few pieces of Blender vocabulary.

## 1. The 3D Viewport

The large area where you see the Minecraft world is the **3D Viewport**.

- **Left mouse button (LMB)** normally selects.
- **Middle mouse button (MMB)** rotates the view.
- **Shift + MMB** pans.
- Mouse wheel zooms.

Minesport adds special FLATTER click handling only when the click actually hits FLATTER logical geometry. Other clicks continue to behave like normal Blender clicks.

## 2. The Outliner

The list of objects in the upper-right part of Blender is the **Outliner**.

If you cannot find a Minesport object in the viewport, search the Outliner for names such as:

- `FLATTER_...`
- `FLATTER_SHAPE_...`
- `Minesport_UserLight_...`
- `MINESPORT_LIGHT_BLOCK_LVL_...`

Clicking an object in the Outliner selects it.

## 3. Object Mode vs Edit Mode

At the top-left of the 3D Viewport Blender shows a mode selector. For normal Minesport FLATTER work, keep it on **Object Mode**.

A FLATTER object is **not** meant to be edited as ordinary merged Blender mesh faces. The visible mesh is a render cache. Minesport keeps the Minecraft blocks in an embedded logical grid.

If you want to edit one Minecraft block, use Minesport's logical selection/materialization tools instead. See **[Page 12 — FLATTER](12.md)**.

## 4. The right sidebar / N-panel

With your mouse over the 3D Viewport, press **N**. A sidebar appears on the right side of that viewport.

Minesport adds a tab named **Minesport** there when the addon is installed and enabled.

If you have never opened it before, continue to **[Page 11 — Find the Minesport Panel](11.md)**.

## 5. Collections

A Blender **Collection** is basically a folder of objects. Minesport may create collections for an export and for lights. Hiding a collection hides those objects from the viewport; disabling render for a collection can also affect final renders.

## 6. The Properties editor

The lower-right area with vertical icons is Blender's **Properties editor**. Minesport can expose object information there too, but beginners should usually start from the easier **3D Viewport → N-panel → Minesport** workflow.
