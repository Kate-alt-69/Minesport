# Fyne → Rust/Slint migration

The archived Go/Fyne desktop is frozen reference code. The active 0.2.0 desktop lives in `/desktop` and is being recreated feature-for-feature in Rust + Slint.

Parity work should use the archived UI to compare behavior, then implement the equivalent behavior in Rust/Slint. New UI fixes and features must not be added to the Fyne archive.
